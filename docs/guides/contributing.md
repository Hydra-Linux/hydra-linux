# Contributing Guide

## Code of Conduct
We strive to be a welcoming and inclusive community.

## How to Contribute
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a Pull Request

## Package Contributions
- Follow the recipe format in `package-creation.md`
- Test locally with `flash make <recipe>`
- CI will validate syntax automatically

## Bug Reports
Open an issue at https://github.com/Hydra-Linux/hydra-linux/issues

## Community
- Matrix: #hydra-linux:matrix.org
- GitHub Discussions
- IRC: irc.libera.chat #hydra-linux
